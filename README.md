# AyuSetu – AI-Based Doctor Appointment System

AyuSetu is a Django-based web application designed to simplify doctor discovery and appointment booking. The system connects patients with doctors and provides an AI/ML-based symptom recommendation feature to help patients identify a suitable medical specialization.

## Features

- Patient Registration and Login
- Doctor Registration and Login
- Admin Authentication and Management
- Doctor Verification by Admin
- Doctor Profile Management
- Medical Specialization Management
- Doctor Search and Filtering
- AI/ML-Based Symptom Recommendation
- Appointment Booking
- Appointment Cancellation
- Appointment History
- Doctor Appointment Management
- Admin Dashboard
- Responsive User Interface

## Technologies Used

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

### Backend
- Python
- Django

### Database
- SQLite3

### Machine Learning
- Python
- Scikit-learn
- Pandas
- NumPy

How It Works
Patient
Register or log in.
Search for doctors or medical specializations.
View doctor profiles.
Use the AI symptom recommendation feature.
Select a suitable doctor.
Book an appointment.
View appointment status and history.
Doctor
Register as a doctor.
Complete the doctor profile.
Wait for admin verification.
Manage availability.
View patient appointments.
Accept, reject, or complete appointments.
Admin
Log in to the admin panel.
Verify registered doctors.
Manage patients and doctors.
Manage medical specializations.
Manage appointments and system data.
AI/ML Feature

AyuSetu includes an AI/ML-based symptom recommendation module that analyzes patient-provided symptoms and recommends a relevant medical specialization.

The ML component is designed to assist patients in navigating the healthcare system and is not intended to replace professional medical diagnosis.

Installation
1. Clone the Repository
git clone https://github.com/sujan2003sikder/AyuSetu---AI-Based-Doctor-Appointment-System.git
2. Open the Project
cd AyuSetu---AI-Based-Doctor-Appointment-System
3. Create a Virtual Environment
python -m venv venv
4. Activate the Virtual Environment

Windows:

venv\Scripts\activate
5. Install Dependencies
pip install -r requirements.txt
6. Apply Migrations
python manage.py migrate
7. Run the Development Server
python manage.py runserver

Open the following address in your browser:

http://127.0.0.1:8000/
